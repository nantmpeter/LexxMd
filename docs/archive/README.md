# Archive

This folder stores historical planning documents that no longer represent the current app state.

Archived documents are useful for understanding how Lexx evolved, but current docs and code should take precedence for implementation facts.

Some archived files mention their original paths, such as `SPEC.md` or `docs/superpowers/...`. Those references are historical and are intentionally left as written.

## Contents

- `2026-04-mvp-planning/` - early Markdown WYSIWYG MVP specs and plans.
- `2026-04-ai-feature-planning/` - early AI feature design and planning notes.

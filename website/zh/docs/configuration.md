# 配置

Lexx 设计为开箱即用，需要最少的配置。大部分设置会自动适应你的系统。

## 主题

Lexx 跟随系统的外观设置：

- **浅色模式** — 当系统处于浅色模式时
- **深色模式** — 当系统处于深色模式时

当你更改系统偏好时主题会自动切换。也可以通过编辑器底部的状态栏按钮手动切换。

## 窗口布局

### 侧边栏
- **隐藏** — 编辑单个文件时（默认）
- **扁平** — 打开多个文件时显示文件标签页
- **树形** — 打开文件夹工作区时显示文件树

在窄窗口中，侧边栏会折叠为边缘触发的浮层——鼠标悬停在左边缘即可显示。

### 大纲视图
打开大纲面板可查看文档中的所有标题。点击任意标题即可跳转。活动标题会在你滚动时高亮同步。

在窄窗口中，大纲视图变为右侧的边缘触发浮层。

## 文件关联

Lexx 注册以下文件类型的关联：

- `.md`
- `.markdown`
- `.mdx`

在系统文件管理器中双击这些文件即可用 Lexx 打开。

## 自动保存

- 未保存的更改每 **3 秒**自动保存到临时文件
- 下次启动时，Lexx 会提示你恢复之前未保存的工作
- 已保存的文件自动将更改保存回原始文件

## 源码模式

在所见即所得和 Markdown 源码编辑之间切换：

- **macOS**：⌘⇧S
- **Windows/Linux**：Ctrl+Shift+S

切换模式时光标位置会自动保持。

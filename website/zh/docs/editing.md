# 编辑

Lexx 采用**双模所见即所得**编辑模型。这意味着你写 Markdown，但看到渲染后的效果——原始语法只在光标所在的块中可见。

## 双模工作原理

1. **聚焦一个块** → 你看到原始 Markdown 语法（`#`、`**`、`>`、`- ` 等）
2. **离开该块** → 语法标记消失，内容渲染为视觉效果
3. **切换即时完成** — 纯 CSS 切换，无 DOM 重建

这让你同时获得两种体验：需要时可以随时查看和编辑原始 Markdown，阅读时文档则呈现干净渲染的效果。

## Markdown 快捷输入

输入以下快捷方式后按空格触发：

| 快捷输入 | 结果 |
|----------|------|
| `# ` | 一级标题 |
| `## ` | 二级标题 |
| `### ` | 三级标题 |
| `> ` | 引用块 |
| `- ` | 无序列表 |
| `1. ` | 有序列表 |
| `- [ ] ` | 任务列表（复选框） |
| `---` | 分隔线 |
| `` ``` `` | 代码块 |

## 行内格式

| 语法 | 结果 |
|------|------|
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `~~删除线~~` | ~~删除线~~ |
| `==高亮==` | 高亮文本 |
| `` `代码` `` | `行内代码` |
| `~下标~` | 下标文本 |
| `^上标^` | 上标文本 |
| `++下划线++` | 下划线文本 |

## 浮动工具栏

选中任意文本后会弹出浮动工具栏：

- **B** — 粗体（⌘B）
- **I** — 斜体（⌘I）
- **S** — 删除线
- **☐** — 切换任务列表
- **H** — 高亮
- **<>** — 行内代码
- **🔗** — 插入/编辑链接（弹出 URL 输入框）
- **X₂** — 下标
- **X²** — 上标
- **U̲** — 下划线

当前激活的格式状态会在工具栏中高亮显示。

## 源码模式

在所见即所得和源码模式之间切换，查看原始 Markdown：

- **macOS**：显示 → 切换源码模式（⌘⇧S）
- **Windows/Linux**：显示 → 切换源码模式（Ctrl+Shift+S）

源码编辑器基于 CodeMirror 6，支持语法高亮、行号和搜索功能。切换模式时自动保持光标位置。

## 链接

1. 选中文本，点击浮动工具栏中的 🔗
2. 在选区下方弹出一个输入框——粘贴或输入 URL
3. 按 Enter 或点击确定应用

要编辑已有链接，点击链接后使用工具栏。弹框会预填当前 URL 并提供**移除**按钮。

## 图片

直接从剪贴板粘贴图片（⌘V / Ctrl+V）。图片会保存到 `.md` 文件旁边的 `assets/` 文件夹中，使用相对路径引用，保持文档的可移植性。

## 富文本代码块

使用特殊语言标记的代码块会渲染实时输出：

- `` ```mermaid `` — 将 Mermaid 图表渲染为 SVG
- `` ```math `` 或 `` ```latex `` — 渲染 KaTeX 数学公式

聚焦代码块可编辑源码，点击其他区域查看渲染结果。

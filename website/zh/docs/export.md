# 导出

Lexx 支持三种导出格式，全部在本地处理，无需任何外部服务。

## PDF 导出

生成多页 A4 PDF 文档，格式整洁。

**操作方式**：文件 → 导出为 PDF

特性：
- A4 页面尺寸，适当边距
- 按块边界分页——不会从块中间截断，超高块会跨页切片
- 输出中隐藏 Markdown 标记
- 代码块带语法高亮
- 嵌入图片和图表
- 注意：页面以图片形式渲染，文字不可选中——需要可选中文字的 PDF 请使用下方的**打印**

## DOCX 导出

生成 Microsoft Word 文档，完整保留格式。

**操作方式**：文件 → 导出为 DOCX

支持的元素：
- 标题（h1–h6）→ Word 标题样式
- 粗体、斜体、删除线、下划线
- 有序和无序列表（嵌套）
- 任务列表带复选框
- 引用块
- 代码块带语法高亮颜色
- 表格带边框
- 嵌入的位图图片（PNG/JPG/GIF/BMP）
- Mermaid/KaTeX 作为嵌入图片
- 超链接

导出完成后会弹出 toast，报告嵌入了多少张图片（以及跳过的数量）。

## JPEG 导出

生成高分辨率 JPEG 图片。

**操作方式**：文件 → 导出为 JPEG

特性：
- 2 倍像素比，在 Retina 显示屏上清晰锐利
- 完整文档捕获
- 渲染模式输出（无语法标记）

## 打印

**操作方式**：文件 → 打印（⌘⌥P / Ctrl+Alt+P）

使用系统打印对话框，其中也提供**存储为 PDF**——输出保留可选中文字，与上面的图片式 PDF 导出不同。

## 注意事项

- 所有导出强制使用**渲染模式**——Markdown 语法标记在输出中隐藏
- 导出通过原生保存对话框完成——由你选择目标文件名和文件夹

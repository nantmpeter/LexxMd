# 导出

Lexx 支持三种导出格式，全部在本地处理，无需任何外部服务。

## PDF 导出

生成多页 A4 PDF 文档，格式整洁。

**操作方式**：文件 → 导出为 PDF（或 ⌘⇧P / Ctrl+Shift+P）

特性：
- A4 页面尺寸，适当边距
- 自动分页
- 输出中隐藏 Markdown 标记
- 代码块带语法高亮
- 嵌入图片和图表

## DOCX 导出

生成 Microsoft Word 文档，完整保留格式。

**操作方式**：文件 → 导出为 DOCX（或 ⌘⇧D / Ctrl+Shift+D）

支持的元素：
- 标题（h1–h6）→ Word 标题样式
- 粗体、斜体、删除线、下划线
- 有序和无序列表（嵌套）
- 任务列表带复选框
- 引用块
- 代码块带语法高亮颜色
- 表格带边框
- Mermaid/KaTeX 作为嵌入图片
- 超链接

## JPEG 导出

生成高分辨率 JPEG 图片。

**操作方式**：文件 → 导出为 JPEG（或 ⌘⇧J / Ctrl+Shift+J）

特性：
- 2 倍像素比，在 Retina 显示屏上清晰锐利
- 完整文档捕获
- 渲染模式输出（无语法标记）

## 注意事项

- 所有导出强制使用**渲染模式**——Markdown 语法标记在输出中隐藏
- 导出文件保存到源 `.md` 文件所在的同一目录
- 对于未保存的文件，导出到下载文件夹

# 快捷键

## 文件操作

| 快捷键 | macOS | Windows/Linux | 操作 |
|--------|-------|---------------|------|
| 新建 | ⌘N | Ctrl+N | 新建未命名文件 |
| 打开 | ⌘O | Ctrl+O | 打开文件对话框 |
| 打开文件夹 | ⌘⇧O | Ctrl+Shift+O | 打开文件夹作为工作区 |
| 快速打开 | ⌘P | Ctrl+P | 快速打开工作区与最近文件 |
| 保存 | ⌘S | Ctrl+S | 保存当前文件 |
| 另存为 | ⌘⇧S | Ctrl+Shift+S | 将当前文件保存到新路径 |
| 打印 | ⌘⌥P | Ctrl+Alt+P | 通过系统对话框打印 |
| 偏好设置 | ⌘, | Ctrl+, | 打开偏好设置 |
| 关闭 | ⌘W | Ctrl+W | 关闭当前标签 |
| | ⌘⇧] | Ctrl+Shift+] | 下一个标签 |
| | ⌘⇧[ | Ctrl+Shift+[ | 上一个标签 |

## 导出

导出没有键盘快捷键——请使用**文件**菜单：

- 文件 → 导出为 PDF...
- 文件 → 导出为 DOCX...
- 文件 → 导出为 JPEG...

## 编辑

| 快捷键 | macOS | Windows/Linux | 操作 |
|--------|-------|---------------|------|
| 查找 | ⌘F | Ctrl+F | 在当前文档中查找（所见即所得模式） |
| 粗体 | ⌘B | Ctrl+B | 切换粗体 |
| 斜体 | ⌘I | Ctrl+I | 切换斜体 |

## 视图

| 快捷键 | macOS | Windows/Linux | 操作 |
|--------|-------|---------------|------|
| 退出源码模式 | Esc | Esc | 返回视觉模式 |
| 全屏 | | | 显示 → 切换全屏 |

源码模式通过**显示**菜单或状态栏按钮切换；进入源码模式没有键盘快捷键。

## Markdown 输入规则

输入以下内容后按空格触发：

| 输入 | 结果 |
|------|------|
| `# ` | 一级标题 |
| `## ` | 二级标题 |
| `### ` | 三级标题 |
| `#### ` | 四级标题 |
| `> ` | 引用块 |
| `- ` | 无序列表 |
| `* ` | 无序列表 |
| `1. ` | 有序列表 |
| `- [ ] ` | 未完成的任务 |
| `- [x] ` | 已完成的任务 |
| `---` | 分隔线 |
| `**文字**` | 粗体 |
| `*文字*` | 斜体 |
| `~~文字~~` | 删除线 |
| `==文字==` | 高亮 |
| `` `文字` `` | 行内代码 |
| `~文字~` | 下标 |
| `^文字^` | 上标 |
| `++文字++` | 下划线 |

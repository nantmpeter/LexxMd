# 特性

## 编辑

### 双模所见即所得
逐块切换。当光标位于某个块中时，你会看到原始 Markdown 语法——标题显示 `#`，粗体显示 `**`，链接显示 `(url)`。移开光标，一切优雅渲染。这完全通过 CSS 实现，零 DOM 重建开销。

### 完整源码模式
一键切换到基于 CodeMirror 6 的 Markdown 源码视图。切换时自动保持光标位置。包含完整的语法高亮、搜索、括号匹配功能。

### 丰富的 Markdown 扩展
- **高亮** — `==文字==` 渲染为高亮文本
- **下标** — `~文字~` 渲染为下标
- **上标** — `^文字^` 渲染为上标
- **下划线** — `++文字++` 渲染为下划线文本
- **任务列表** — `- [ ]` 和 `- [x]` 实时复选框
- **表格** — 可视化可调整大小的表格

### 浮动工具栏
选中文本后弹出浮动工具栏：粗体、斜体、删除线、复选框、高亮、行内代码、链接、下标、上标、下划线。

## 渲染

### Mermaid 图表
标记为 `mermaid` 的代码块会自动渲染为 SVG 图表。聚焦编辑源码，失焦查看渲染结果。支持流程图、时序图、甘特图等。

### KaTeX 数学公式
`math` 或 `latex` 代码块通过 KaTeX 渲染精美的排版公式。支持完整的 LaTeX 语法。

### 语法高亮
代码块通过 lowlight（兼容 highlight.js）自动对 20+ 种编程语言进行语法高亮。

## 导出

### PDF
多页 A4 PDF 导出，自动分页。干净的输出，无 Markdown 标记残留。

### DOCX
完整的 DOCX 生成，支持标题、段落、列表（嵌套）、带语法颜色的代码块、表格、嵌入的图表图片和任务列表复选框。

### JPEG
通过 html2canvas 生成高质量的 2 倍像素比 JPEG 导出。

## 工作区

### 多窗口
在独立窗口中打开多个文件。支持 `.md`、`.markdown`、`.mdx` 文件关联，双击即可从操作系统打开。

### 文件夹工作区
打开文件夹后在侧边栏树形视图中浏览文件。懒加载目录内容，导航迅速。

### 大纲视图
浮动大纲面板显示所有标题（h1-h6）。点击即可滚动定位。活动标题跟踪与滚动位置同步。

## 可靠性

### 崩溃恢复
每 3 秒自动将未保存的内容保存到临时文件。重启时提示恢复上次会话的工作内容。

### 自动保存
修改后的文件在 3 秒无操作后自动保存。
